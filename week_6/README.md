# Задание №1. Анализ кризисной ситуации

**Кейс: угроза от крупного конкурента**

На рынок выходит крупная IT-компания с похожим продуктом и большими возможностями для продвижения. Для Student Pass это может привести к снижению интереса пользователей и усложнить привлечение новых студентов.

**Основные причины кризиса:**
- появление сильного конкурента;
- более высокий рекламный бюджет конкурента;
- риск потери части аудитории.

**Возможные последствия:**
- снижение количества новых пользователей;
- сложности с привлечением партнёров;
- необходимость усилить продвижение продукта.

**Меры по стабилизации:** сосредоточиться на студенческой аудитории, развивать партнёрскую сеть и улучшать сам сервис.

# Задание №2. Разработка антикризисной стратегии

Основная цель стратегии — сохранить пользователей и усилить позиции Student Pass.

**План действий:**

1. Проанализировать предложения и сильные стороны конкурента.
2. Определить преимущества Student Pass.
3. Увеличить количество партнёров и интересных предложений для студентов.
4. Усилить продвижение через социальные сети и студенческие сообщества.
5. Собрать обратную связь пользователей и использовать её для развития продукта.

**Распределение ролей:**

- **разработчик** — улучшение и развитие сервиса;
- **ответственный за продукт** — анализ конкурентов и планирование изменений;
- **ответственный за продвижение** — работа с аудиторией и социальными сетями.

**Коммуникация:** команда регулярно обсуждает результаты и изменения, а пользователям сообщает о новых возможностях и преимуществах Student Pass.

# Задание №3. Адаптация к изменениям рынка

Если на рынке появляется крупный конкурент, Student Pass не должен полностью менять свою концепцию. Основной акцент следует сделать на своей целевой аудитории — студентах.

**Основные изменения:**

- расширить количество партнёров;
- добавлять более востребованные студентами предложения;
- улучшать удобство использования сервиса;
- активнее работать со студенческими сообществами;
- регулярно анализировать действия конкурентов и отзывы пользователей.

Таким образом, Student Pass сможет сохранить свою аудиторию и постепенно укреплять позиции на рынке.
